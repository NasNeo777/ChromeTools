# 视频练习与界面升级

共享两平台字幕缓存，通过独立练习模块配置难度、题型和数量（3–12 题）。固定难度：简单=原文复述，中等=理解对比，困难=应用验算/代码判错。后台要求结构化 JSON 并校验题数、类型、答案、评分标准与字幕依据；将字幕和学生答案视为资料，不执行其中指令。

每题 10 分。选择题本地判分，空白答案直接记零，填空与问答基于参考答案、评分要点和字幕进行 AI 批改。验证完整批改结果后统一显示总分、逐题反馈与参考答案。失败保留作答，允许重试。试卷与答案单独导出可打印 HTML，打印时可另存 PDF。练习与作答存于当前页内存，不增加存储权限。

保留原生 JavaScript 架构，避免引入构建工具与远程资源。共享侧栏和设置弹窗统一为中性灰、绿色强调、磨砂层次、清晰字号与键盘焦点，兼容窄屏、深色与减少动态效果。

验证：Node 单元测试覆盖结构校验、评分边界、输出转义与试卷答案分离；模拟 Chrome Port 验证后台协议；DOM 集成检查配置、生成、作答、批改和导出，检查 JS 语法和 manifest 资源。
