# 自定义提示词工具（1.7.0）

用户可在扩展设置中保存按钮名称、提示词、适用范围（所有页面/普通网页/视频页），并编辑、启用/停用、删除工具。自定义工具独立写入chrome.storage.local，不依赖API设置校验，不改动现有服务商及偏好。限制20个工具、名称24字符、提示词12,000字符，以保证菜单可用与本地存储有界。

内容脚本通过storage.onChanged实时更新同一个AI工具箱菜单中的「我的工具」分组。点击后读取当前适配器的页面正文或视频字幕，后台按保存的工具ID重新验证启用状态与范围，再调用当前服务商的已有流式通道。网页正文仍每次重新提取；字幕仍复用缓存。原有内置功能保持。

自定义指令与原文资料分别发送，输出沿用侧栏、追问、复制和HTML下载。后台完成事件返回实际使用的工具快照，后续追问保留该快照，避免编辑工具影响已生成的对话。生成文档使用标签和属性白名单渲染，保留原有徽章、评分条、表格与时间戳，同时支持安全展示代码文本；不加载生成内容里的远程资源或执行脚本。

验证包括共享数据校验、范围过滤、后台工具解析与快照追问、设置独立保存、长提示词、跨页菜单更新、生成与导出，以及原有视频练习、网页总结和多服务商配置回归。
