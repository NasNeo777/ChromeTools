# AI工具箱：网页、服务商和统一入口

在保留原有两平台适配器、批判性分析提示词、全文翻译、评论印证、追问、练习和导出的前提下，增加普通网页适配器。所有HTTP/HTTPS页面加载同一组脚本，由共享层按路由优先选择视频适配器，再回退到网页适配器。普通网页每次操作提取可见正文，不读取表单或隐藏内容；超过48,000字符显式标注截断。

入口为单按钮，菜单锚定按钮展开，支持Escape、方向键、外部点击和焦点离开关闭。按平台展示原有五个视频操作或两个页面操作。

新增共享providers模块，独立保存每家Key、模型与Base URL，保留旧apiKey/model字段作为DeepSeek兼容。请求时只使用当前服务商凭证。Claude单独处理Messages协议与text_delta；其他服务商使用Chat Completions。统一检测空回复、错误流和截断，阻止静默成功。网页的总结、追问及练习使用正文提示词。

新logo由imagegen生成，原稿及扩展尺寸保存在icons，旧图标独立备份。验证包括旧配置兼容、多凭证隔离、协议转换、原有视频练习流程、页面正文提取、路由识别与单按钮菜单。
