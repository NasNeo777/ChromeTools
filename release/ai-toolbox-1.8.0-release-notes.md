# AI工具箱 1.8.0

发布文件：ai-toolbox-1.8.0-chrome-web-store.zip

## 更新内容

- 新增右键“AI 总结”：解释选词、总结选段，支持连续追问；可附上模型推测的出处线索，未经联网核验。
- 工具箱支持拖动并记住位置。
- 出题自动记住上次有效的难度、题型和题数。
- 功能菜单加入图标。
- 修复深色模式跟随、文字对比度和网站样式干扰问题。

- 版本号：1.8.0（原发布版本为 1.7.0）。
